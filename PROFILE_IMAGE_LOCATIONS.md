Image States & Behavior\n\n### State 1: No Profile Image (Initial)\n```\n┌──────────────┐\n│              │\n│    Blue      │  Display: User initials\n│  Gradient    │  Text: White, bold, uppercase\n│              │  Example: \"AU\" for Admin User\n│   INITIALS   │\n│              │\n└──────────────┘\n```\n\n### State 2: Image Uploading\n```\n┌──────────────┐\n│              │\n│  [Loading]   │ Data Flow Diagram\n\n```\n┌─────────────────┐\n│  User Uploads   │\n│    Image        │\n└────────┬────────┘\n         │\n         ▼\n┌─────────────────┐\n│   Frontend      │\n│  - Validate     │\n│  - Create       │\n│    preview      │\n└────────┬────────┘\n         │\n         ▼\n┌─────────────────┐\n│  Send to        │\n│  Backend        │\n│  (FormData)     │\n└────────┬────────┘\n         │\n         ▼\n┌─────────────────┐\n│  Backend        │\n│  - Upload to S3 │\n│  - Get S3 URL   │\n│  - Save to DB   │\n│  - Return URL   │\n└────────┬────────┘\n         │\n         ▼\n┌─────────────────┐\n│  Frontend       │\n│  - Update store │\n│  - Show image   │\n│    everywhere   │\n└─────────────────┘\n```\n\n---\n\n## Size Reference Chart\n\n| Location | Size | Purpose |\n|----------|------|----------|\n| Sidebar user | 12x12 px | Quick user identification |\n| Header toggle | 8x8 px | Minimal header space |\n| Header dropdown | 12x12 px | Better visibility in menu |\n| Admin table | 10x10 px | Space-efficient table display |\n| Profile page | 32x32 px | Main profile view |\n| Upload target | 128x128 px | Full-screen profile edit |\n\n---\n\n## Responsive Behavior\n\n### Desktop (≥768px)\n- Sidebar always visible (left side)\n- Header full-width with profile dropdown\n- Admin table displays in full width\n- Profile page spans full container\n\n### Tablet/Mobile (<768px)\n- Sidebar collapses/hides (toggle with ☰)\n- Header compact with profile avatar\n- Admin table remains responsive\n- Profile page optimized for mobile\n\n---\n\n## Browser Display Examples\n\n### Example 1: New User (No Image)\n```\nSidebar shows:  [AU] Admin User\nHeader shows:   [AU] ▼\nAdmin table:    [AU] test@mail | PENDING\n```\n\n### Example 2: After Image Upload\n```\nSidebar shows:  [📷 actual photo]\nHeader shows:   [📷 actual photo] ▼\nAdmin table:    [📷 actual photo] john@mail | PENDING\nProfile page:   Large [📷 actual photo] for editing\n```\n\n---\n\n## Error Handling\n\n### If Image Load Fails\n- S3 URL dead/expired → Shows initials fallback\n- Network error → Shows initials from cache\n- Invalid image → Rejected before upload\n\n### If Upload Fails\n- Shows error toast notification\n- Keeps current image (no change)\n- Allows retry\n\n---\n\n## Performance Notes\n\n✅ **Images cached** by browser after first load\n✅ **Initials** generate instantly (no network)\n✅ **S3 URLs** reused via auth store (no re-fetches)\n✅ **Multiple sizes** served from same S3 object\n✅ **Lazy loading** via native img tag\n\n---\n\n## Accessibility Features\n\n✅ **Alt text**: \"Profile\" on all img tags\n✅ **Contrast**: Gradient background ensures readability\n✅ **Fallback**: Initials readable without images\n✅ **ARIA labels**: Proper button/dropdown structure\n✅ **Keyboard nav**: Full keyboard support for dropdowns\n\n
